# أنيميشن على فيديو talking-head عربي

بتصمّم الجرافيك بـ HTML و CSS، بيترندر صور بقناة ألفا، وبيتسلّم كملف تايملاين
تستورده في المونتاج فتلاقي كل حاجة في مكانها بالفريم.

مفيش After Effects، ومفيش سحب وإفلات على تايملاين، ومفيش إعادة شغل من الأول لما
تغيّر كلمة. لو غيّرت النص، بتشغّل أمر واحد وبيتعمل من جديد بالظبط زي ما كان.

**اللي بيطلع منه:** ملفات ProRes 4444 بقناة ألفا + ملف FCPXML. تستورد الملف في
DaVinci Resolve فتلاقي الفيديو على V1 والأنيميشنز على V2 كل واحد في فريمه.

---

## القيمة الأساسية — التوقيت

ده مش شغل تصميم بس. ده شغل توقيت. القاعدة اللي كل حاجة واقفة عليها:

> **الأنيميشن مايبدأش قبل ما الكلام الخاص بيه يتقال، ومايخلصش قبل ما الكلام ينتهي.**

عشان كده التوقيت بيتاخد من **الصوت نفسه** — مش من السكربت المكتوب ولا بالتخمين.
بنعمل transcript فيه توقيت كل كلمة لوحدها، وكل عنصر جوه المشهد بيظهر على الكلمة
اللي بتسمّيه.

الفرق ده هو اللي بيخلي الأنيميشن يحس إنه جزء من الفيديو، مش حاجة اتحطّت فوقه.

## اللي هتحتاجه

```bash
bin/setup.sh
```

بيفحص كل حاجة ويقولك الناقص والأمر اللي ينزّله. المطلوب: `ffmpeg`، `node`،
`python3`، `whisper-cpp`، متصفح Chrome، وموديل whisper (٣ چيجا، مرة واحدة بس).

## الفكرة في ٦ خطوات

| | الخطوة | الأمر | بيطلع إيه |
|---|---|---|---|
| ١ | افحص الفيديو | `bin/1-probe.sh فيديو.mov` | `project.json` |
| ٢ | transcript بتوقيت كل كلمة | `bin/2-transcribe.sh` | `words.txt` + `captions.srt` |

| ٦ | ولّد التايملاين | `bin/6-timeline.py` | `*.fcpxml` |

وحاجتين اختياريتين بره الترتيب ده:

| الخطوة | الأمر | بيطلع إيه |
|---|---|---|
| اطبع ألوانك من الموقع | `bin/apply-config.py` | بيعدّل `tokens/digitalflow.css` |
| ابصم الكابشنز على الصورة | `bin/7-captions.sh` | `out/captioned.mp4` |

`apply-config.py` بياخد `config.json` — الملف اللي الموقع بينزّله مع البرومبت — وبيحطّ
ألوانك وخطك في التوكنز. من غيره الأنيميشن هيطلع بألوان الكيت الافتراضية مش بتاعتك،
فشغّله **قبل** ما ترندر.

`7-captions.sh` بياخد `captions.srt` وبيحرقه في الصورة. مش بيستخدم فلتر `subtitles`
بتاع ffmpeg — ده محتاج libass، وفي نسخ ffmpeg كتير مش موجود فيها، وشكل العربي فيه
بيختلف على حسب البيلد. بدالها بيعدّي على نفس مسار الكيت: HTML ← PNG بألفا ← تركيب.
وبيسيبلك كمان `out/captions.mov` بألفا لو فضّلت تركّبها في المونتاج بدل الحرق.

## ابدأ من هنا

### ١. افحص الفيديو

```bash
bin/1-probe.sh ~/Videos/lesson-01.mov
```

بيقرا المقاس والفريم ريت والتايم كود، **وبيقيس الشرايط السودا بنفسه** عند ٣ نقط
مختلفة من الفيديو.

الشرايط دي مهمة أكتر مما تتخيّل. لو الفيديو جواه شرايط والتسليم اتعمل على مقاس
الإطار بدل مقاس الصورة، كل حاجة هتتزحلق ومش هتعرف السبب. الأداة بتحسبها وبتقولك
تعمل إيه.

### ٢. اعمل الـ transcript

```bash
bin/2-transcribe.sh
```

بياخد وقت على قد طول الفيديو تقريباً. بيطلع `words.txt` — كل كلمة في سطر بتوقيتها:

```
 142   107.89   108.27  لعميل
 143   108.27   108.54  كان
 144   108.54   108.99  بيبيع
```

**ده الملف اللي هتعيش فيه.** كل رقم توقيت في أي مشهد بتاخده من هنا. عايز تعرف
الكلمة الفلانية بتتقال إمتى؟

```bash
grep 'بيبيع' words.txt
```

> whisper بيكتب العامية المصرية بصيغة قريبة من الفصحى، فالنص مش هيطابق السكربت
> اللي كتبته حرفياً. متدوّرش على الجملة كاملة — دوّر على كلمة مميزة فيها.

### ٣. اعرف مكان المتكلم

```bash
bin/3-safezones.sh
```

بيطلع فريم من الفيديو وعليه شبكة إحداثيات. افتحه وسجّل ٤ أرقام:

- **الوش**: من x كام لـ x كام
- **الدقن**: عند y كام ← أهم رقم في الملف كله
- **المايك والإيدين**: من y كام

القاعدة: أي كارت في النص التحتاني لازم يبدأ **تحت الدقن بـ100 بكسل على الأقل**.
والنتيجة الطبيعية للقاعدة دي إن الكارت لازم يبقى **عريض وقصير** — لأن المحتوى لو
اترصّ بالطول هيعدّي الحد.

### ٤. اعمل مشهد

```bash
bin/new-scene.sh 01-lower-third 01-intro
```

بينسخ قالب لـ `scenes/01-intro.html` ويظبط مساراته. افتحه وغيّر النص، وحطّ توقيت
كل عنصر من `words.txt`.

شوف كل القوالب:

```bash
ls templates
```

راجع شكله في أي لحظة:

```bash
node bin/check.js scenes/01-intro.html /tmp/x.png 8
```

واقيس مكانه بالأرقام:

```bash
node bin/measure.js scenes/01-intro.html 8 .lower
```

### ٥. حدّد أماكن المشاهد على التايملاين

```bash
bin/plan.py 01-intro 12.4 26.8  02-problem 28.0 44.2
```

بتديله اسم المشهد ووقت دخوله وخروجه بالثواني، وهو بيحوّلهم لفريمات، وبيتأكد إن
مفيش كليبين متصادمين، وبيقولك التغطية الكلية كام في المية.

### ٦. راجع قبل ما ترندر

```bash
bin/4-review.sh
```

بيطلع فريم من كل مشهد **مركّب على فريم حقيقي من الفيديو في نفس اللحظة**، ويحطّهم
في `review/`.

الخطوة دي مش رفاهية. المراجعة بتاخد ثواني والرندر بياخد دقايق أو ساعات. أي غلطة
في المكان أو الحجم هتشوفها هنا بدل ما تكتشفها بعد ساعة رندر.

### ٧. ارندر وسلّم

```bash
bin/5-render.sh          # كل المشاهد، ٤ بالتوازي
bin/check-alpha.sh       # اتأكد إن الكت‑أوايز بتسيب الشاشة نضيفة
bin/6-timeline.py        # يطابق الماسترز ويولّد الـ FCPXML
```

## إزاي تكتب مشهد

كل مشهد ملف HTML واحد بيعرّف حاجة واحدة:

```js
window.SCENE = {
  width: 1920, height: 1080,   // كانفاس التأليف — دايماً 1920×1080
  duration: 14.5,              // بالثواني
  seek(t) {
    // t = ثواني من بداية المشهد. إنت اللي بتحدد شكل الشاشة عند اللحظة دي.
  }
};
```

**التحكم في الزمن بـ `seek(t)` مش بـ CSS animation.** المتصفح مش بيشغّل حاجة —
إحنا بنقوله "ارسملي شكل الشاشة عند الثانية ٣.٧" وبناخد صورة. النتيجة دقيقة للفريم،
ولو رندرت نفس المشهد تاني بيطلع بالحرف زي ما كان.

مش محتاج تحدّد الحجم النهائي — الكيت بياخده من `project.json`.

### الدوال الجاهزة

في `scenes/anim.js`:

| الدالة | بتعمل إيه |
|---|---|
| `win(t, start, dur)` | رقم من ٠ لـ١ بيبدأ عند `start` وياخد `dur` ثانية، مُخفَّف |
| `rise(el, t, start)` | العنصر يظهر مع انزلاق بسيط لفوق |
| `slideIn(el, t, start)` | انزلاق من اليمين |
| `drift(a, b, t)` | حركة بطيئة جداً للخلفيات الملوّنة |

### مثال

```js
seek(t) {
  rise(title, t, 0.00);    // العنوان يظهر مع أول كلمة
  rise(line1, t, 3.40);    // النقطة الأولى عند الثانية ٣.٤
  rise(line2, t, 7.10);    // والتانية عند ٧.١
  box.style.opacity = win(t, 0, 0.5) * (1 - win(t, 12.8, 0.5));
  //                   ^ يدخل في نص ثانية      ^ ويخرج عند ١٢.٨
}
```

الأرقام دي (٣.٤ و ٧.١ و ١٢.٨) كلها من `words.txt`، ناقص وقت بداية المشهد.

## القواعد اللي بتفرق

**التغطية.** الأنيميشن على ٧٥–٨٥٪ من زمن الفيديو معقول. أعلى من كده بيبقى تقيل،
وأقل بيبقى الفيديو فاضي.

**الكت‑أواي في حدود ٢٠–٣٥٪.** لأنه بيغطي المتكلم. اللي فوق كده بيخلي المشاهد
ينسى إن فيه حد بيكلمه.

**سيب مساحات وش صافي عن قصد.** اللحظة اللي بيتكلم فيها من قلبه مش محتاجة كارت.
الكارت هيقطعها.

**في العربي أول عنصر في الـ flex بيروح يمين.** الكارت اللي بتشرحه الأول لازم يبقى
هو أول واحد في الـHTML، وإلا هيفضل الكارت التاني معلّق لوحده في الناحية الغلط لحد
ما دوره ييجي.

**سهم التدفّق بيروح شمال.** المدخل يمين ← السهم ← المخرج شمال. دي أشهر غلطة RTL.

**كرّر الشيء اللي بتبنيه، متوصفهوش.** لو بتشرح قالب من ٤ أركان، اعرضه مصغّر فوق
كل كارت والجزء النشط بس منوّر. المشاهد مايتوهش وإنت مش بتصرف كلام على "إحنا
دلوقتي في الركن التاني".

**احكم على القايمة في مكانها.** لو بتفلتر ١٠ عناصر، اعرضهم كلهم من أول فريم
باهتين وخلّي **الحكم** هو اللي يتحرك. آخر لقطة بتبقى الحجة كلها في صورة واحدة.

**المشهد الأخير خليه كارت مش كت‑أواي**، عشان المتكلم يفضل ظاهر في التوديع — ومن
غير فيد أوت لأنه لسه بيتكلم في آخر فريم.

## الفخاخ — كلهم اتقابلوا فعلاً

**١. خلفية الكت‑أواي لازم تكون جوه عنصر، مش على `body`.**
الخلفية اللي على `body` بتتنقل لـ canvas الصفحة اللي برّه الـ opacity group بتاع
body. فلما تعمل fade، المحتوى يختفي والخلفية تفضل معتمة — والمشهد يقفل الشاشة
للأبد. حطها على `.cutbg` جوه `.root`، وافحصها بـ `bin/check-alpha.sh`.

**٢. لو الـ PNG طلع من غير قناة ألفا** يبقى الإطار كله معتم. غالباً غلط في
التصميم مش عطل في الأدوات.

**٣. تصادم الكليبات.** لازم ٦ فريمات على الأقل بين نهاية كليب وبداية اللي بعده.
`bin/plan.py` بيتأكد من دي قبل ما يكتب أي حاجة.

**٤. التايم كود بتاع المصدر.** لو الفيديو جواه تايم كود بيبدأ من 01:00:00:00،
Resolve بيعتبر إن الملف بيبدأ عند فريم ٨٦٤٠٠. لو التايملاين قال `0s` الكليب
هيستورد **Media Offline**. الكيت بيقرا التايم كود الحقيقي ويكتبه.

**٥. الأوفست بتاع الكليب المتصل** بيتقاس من بداية **الكليب الأب** مش من بداية
التايملاين. لو نسيت تضيف التايم كود، كل الأنيميشنز هتترص في أول التايملاين
والفيديو هيتدفع للآخر.

**٦. Resolve بياخد مقاس التايملاين من إعدادات البروجيكت، مش من الملف.** ظبّطه
يدوي قبل الاستيراد. `bin/6-timeline.py` بيطبعلك الأرقام المطلوبة.

**٧. ffmpeg بيقرا من stdin.** لو حطيته جوه `while read` هيبلع سطور من المدخل
وهتلاقي مشاهد بتتخطى أو أسماء بتتقص (`02-x` بتوصل `2-x`). أي `ffmpeg` جوه لوب
لازم ياخد `-nostdin`.

**٨. المعاينة المركّبة لازم تصغّر الفيديو الأول.** المشهد بيترندر على مقاس
الكانفاس والفيديو 4K — لو ركّبتهم على بعض من غير تصغير، كل كارت هيقع بنص حجمه في
ركن الشاشة.

**٩. الرندر ممكن يعلّق عند إغلاق المتصفح.** الفريمات كلها بتبقى على الديسك
والبروسيس مش بيخرج، فالترميز اللي وراه عمره ما بيبدأ. الكيت بيقفل بعد ٥ ثواني
غصب.

**١٠. استنى البروسيس يخلص، متعدّش الملفات.** ffmpeg بينشئ ملف الخرج من أول ثانية
في الترميز، فعدّ الملفات بيعدّي والملف الأخير لسه بيتكتب.

**١١. أربع نسخ Chrome بترندر 4K في نفس الوقت ممكن تخنق بعض.** الـtimeout الافتراضي
بيضرب في نص التصوير, والرندر بيموت برسايل مالهاش علاقة بالسبب: `Target closed` أو
`detached Frame` أو `captureScreenshot timed out`. الكيت رافع الـtimeout لعشر دقايق,
وعلى الجهاز اللي بيزنق شغّل الرندر باتنين بدل أربعة:

    JOBS=2 bin/5-render.sh

وقبل ما تولّد التايملاين, عُدّ الماسترز. `bin/6-timeline.py` بيوقفك لو ملف ناقص.

## التسليم في DaVinci Resolve

التسليم بيبقى ملف تستورده، مش سكربت بيشغّل Resolve.

تصحيح: كنت كاتب هنا إن النسخة المجانية مالهاش scripting API. الـREADME الرسمي اللي
بيتركّب مع Resolve 21.0.4 بيقول العكس — إن الـAPI بيغطي المجاني والـStudio الاتنين،
وإن السكربتات تتنادى من الـConsole أو من سطر الأوامر. الموضوع ده لسه محتاج تأكيد عملي
(الاختبار محتاج Resolve مفتوح).

بس حتى لو الـAPI شغّال، ملف التايملاين أحسن هنا: مش محتاج البرنامج يكون فاتح، وبيتقارن
بـdiff، وبيفضل شغّال مع تغيّر إصدارات Resolve.

قبل الاستيراد — **Project Settings ← Master Settings**:

- Timeline Resolution = المقاس اللي `bin/6-timeline.py` طبعه
- Timeline Frame Rate = فريم ريت المصدر
- لو المصدر فيه شرايط: **Image Scaling ← Mismatched Resolution ← Center crop with no resizing**

وبعدين **File ← Import ← Timeline…**

بيتعمل تايملاين جديد: الفيديو على V1، الصوت على A1، الأنيميشنز على V2 في أماكنها.
ألفا الـ ProRes 4444 بتركّبهم من غير أي ضبط.

## تغيير الهوية البصرية

كل الألوان والخطوط في `tokens/digitalflow.css`. غيّر القيم اللي فيه وكل المشاهد
هتتغير معاها. المتغيرات الأساسية:

```css
--df-primary   /* اللون الأساسي */
--df-accent    /* لون التأكيد */
--df-gradient  /* الجراديينت */
--df-ink       /* لون النص */
--df-bg        /* خلفية الكت‑أواي */
--df-surface   /* خلفية الكروت */
--df-font      /* الخط */
```

الخطوط في `fonts/` — لو غيّرتها، غيّر `fonts/fonts.css` معاها.
