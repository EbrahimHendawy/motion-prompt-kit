# قوالب رأسية (٩:١٦)

القوالب في `templates/` الأصلية مصمّمة على كانفاس أفقي ١٩٢٠×١٠٨٠. القوالب هنا
مصمّمة على **١٠٨٠×١٩٢٠** للريلز.

الفرق مش المقاس بس. في الكادر الرأسي القريب الوش بياخد النص، ومفيش أعمدة جانبية
تحط فيها حاجة. فالمساحات المتاحة بتبقى:

- **شريط علوي** فوق الراس — عادةً `y 40–320`، بعرض الكادر كله
- **شاشة كاملة** (كت أواي) للحظات اللي محتاجة كل الانتباه
- **منطقة الصدر** للكابشنز — سادة غالباً، وإيد المتكلم بتعدّي عليها أحياناً وده مقبول

**شغّل `bin/3-safezones.sh` الأول** — الأرقام دي تقريبية، والخريطة بتديك أرقام
فيديوك إنت.

## المقاسات

الكانفاس ١٠٨٠ عرض بس المشاهدة على موبايل، فالخط لازم يكبر:

    عنوان الشريط العلوي   64–72px / 700
    نص البند              44–48px / 600
    رقم بطل               140–180px / 700
    كابشن                 46–52px / 600

كل مشهد رأسي لازم يبدأ بـ:

    :root { --w:1080px; --h:1920px; }

عشان `base.css` ياخد المقاس الصح.
