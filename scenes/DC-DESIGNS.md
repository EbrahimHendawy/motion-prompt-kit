# تصميمات Claude Design جوه الكيت

`dc-runtime.js` بيخلّي أي تصميم متعمل في Claude Design يشتغل في الكيت **من غير
إعادة كتابة الماركب**.

## المشكلة اللي بيحلّها

صفحة التصميم بتشغّل الحركة بأنيميشن CSS: العنصر عليه `data-a="rise"` و`--d`
للتأخير، والمتصفح بيلعبها بنفسه. ده كويس للمعاينة وبايظ للرندر — الكيت بيصوّر
فريم فريم وبينادي `seek(t)`، والأنيميشن اللي بيلعب لوحده بيدي فريمات مختلفة كل
مرة، فالرندر بيطلع مهزوز.

`dc-runtime.js` بيقرا نفس الوسوم وبيحسب الستايل من `t` مباشرة.

## الاستخدام

```html
<script src="../scenes/dc-runtime.js"></script>
<script>
  const seek = DC.scene(document);          // أو DC.scene(element)
  window.SCENE = { width:1920, height:1080, duration:8, seek };
  seek(0);
</script>
```

والماركب يفضل زي ما هو من التصميم بالحرف.

## اللي بيدعمه

| `data-a` | المدة | الحركة |
|---|---|---|
| `rise` | .72s | ظهور + صعود 34px |
| `right` / `left` | .74s | ظهور + انزلاق 90px |
| `fade` | .60s | ظهور |
| `pop` | .58s | ظهور + تكبير .7 ← 1.06 ← 1 |
| `mask` | .80s | كشف من اليمين |
| `scale` | .78s | ظهور + تكبير .9 ← 1 |
| `unfold` | .70s | فتح لتحت |
| `hold` | `--l` | ظهور ← ثبات ← اختفاء |
| `barx` / `bary` | .70s | شريط بيتمدّ |
| `draw` | `--dur` | رسم مسار SVG |
| `stamp` | .50s | ختم بيهبط |

المستمرة: `data-k="pulse|ken|scroll|glow|float"`.
والعدّادات: `data-count-to` مع `data-count-delay` و`data-count-dur`،
وزوّد `data-count-ar="1"` لو عايز أرقام عربية-هندية.

## فخّان اتقابلوا فعلاً

**التسهيل بين كل نقطتين، مش على المدة كلها.** حركة زي `pop` عندها تلات نقاط
(0 / 60% / 100%). CSS بيطبّق المنحنى على كل مقطع لوحده. لو حسبته على المدة كلها
العنصر بيطلع باهت في وقت المفروض يكون ظاهر فيه — وده فرق بيبان بالعين.

**`draw` والطول المعياري.** لو المسار عليه `pathLength="1"` يبقى الطول معياري،
و`stroke-dasharray` لازم تاخد نفس الرقم مش `getTotalLength()`.

## إزاي تتأكد إن التحويل مطابق

ارندر نفس الماركب بالطريقتين عند نفس اللحظة وقارن البكسلات: مرة بأنيميشن CSS
متجمّد بـ`getAnimations().forEach(a => { a.pause(); a.currentTime = t*1000 })`،
ومرة بـ`seek(t)`. لو فيه فرق يبقى في حركة اتحسبت غلط.

الـ١٥ فكرة في مجموعة Hendawy Tech اتفحصوا كده وطلعوا تحت 1٪ فرق.
